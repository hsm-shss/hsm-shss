## 📘 使用說明

1. 課堂投影或學生自學，直接開啟上方 GitHub Pages 連結即可。  
2. 各頁為單檔 HTML（Tailwind CDN），大多可離線使用（需一次載入 CDN）。  
3. 歡迎老師按課題擴充；程式碼見 [`phy-sim`](https://github.com/hsm-shss/phy-sim) 倉庫。
